初探FlipJump的程序

FlipJump 是一种极简的 esolang，核心指令只有一个：

含义是：

也就是：

  1. 翻转内存地址 a 指向的一个 bit；
  2. 把指令指针跳到地址 b

FlipJump 的特殊之处在于：指令执行本身会修改内存。被修改的 bit 可能正好属于后续指令的跳转地址，于是程序就能实现条件分支、循环、变量、函数调用等高级结构。这也是它看起来不像普通汇编，但依然可以完成通用计算的原因

.fjm 是 FlipJump 的机器码/内存镜像格式。它不是普通的连续指令流，而是一个可以表示稀疏内存的文件格式，里面保存：

  • 内存宽度，例如 32 位或 64 位；
  • FlipJump 指令和数据所在的内存地址；
  • 稀疏内存段；
  • 输入输出相关区域

c2fj 则是 C 到 FlipJump 的编译工具链，可以把普通 C 程序编译成 FlipJump 程序。也就是说，开发者可以用 C 写逻辑，最后生成 .fjm 文件运行

用 FlipJump 官方 Reader 解析

在这道题里，把 FJM 用 Reader 解出来后，发现其高地址内存区不是普通 FJ 数据，而是按照固定规律编码的一段 RV32 little-endian 字节流

这个布局正好对应 c2fj 的 guest memory 映射方式：一个 guest byte 用两个 FlipJump word 表示，word 中的值按 dw = 128 缩放
